# ElderWood RP

Serveur roleplay **nanos world** inspiré de l'univers de Harry Potter.

Ce dépôt centralise toute la documentation du serveur : l'histoire du monde, les règles à respecter, les conseils pour bien jouer et les fiches des personnages.

## Organisation

| Dossier | Contenu |
|---|---|
| [`lore/`](lore/) | L'univers d'ElderWood : histoire, lieux, factions, magie |
| [`reglement/`](reglement/) | Le règlement du serveur |
| [`conseils/`](conseils/) | Conseils et bonnes pratiques de roleplay |
| [`personnages/`](personnages/) | Les fiches personnages (un fichier par personnage) |
| [`site/`](site/) | Le site web du serveur (lore, règlement, whitelist) |

## Créer un personnage

Copie le modèle [`personnages/_modele.md`](personnages/_modele.md), renomme-le avec le nom de ton personnage (par exemple `personnages/elara-vance.md`) et remplis chaque section.
