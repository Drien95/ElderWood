# Fiche 6 — Glossaire du lore

> Source : `lore/05-glossaire.md` et termes définis ailleurs dans le lore. Rien d'ajouté.

| Terme | Définition |
|---|---|
| **Écho** | Aussi appelé magie, l'origine de toute chose. Le « Premier Murmure ». |
| **Résonance** | Réponse propre de chaque être à l'Écho, deux prédispositions génétiques : ressentir et contrôler. |
| **Flux** | Énergie née de la rencontre entre l'Écho et la Résonance. |
| **Résonant** | Sorcier : Résonance assez forte pour un Flux exploitable. |
| **Sans-Flux** | Humain dont la Résonance est trop faible pour un Flux exploitable. |
| **Dissonant** | Né de parents Sans-Flux, **une seule** des deux prédispositions. |
| **Dissonant (résonant)** | Né de parents Sans-Flux, **les deux** prédispositions : peut aller à Elderwood. |
| **Voile** | Phénomène qui dissimule un lieu chargé de Flux aux Sans-Flux (naturel ou artificiel). |
| **Catalyseur** | Objet qui canalise le Flux : baguette, sceptre, bâton, flûte, tout instrument magique. |
| **Source de Vehr** | « La Source », bassin qui révèle la couleur du Flux. |
| **Magie d'usage** | Magie du quotidien, par le geste et l'instant. |
| **Runomancie** | Inscrire le Flux dans la durée par des runes (fréquences en symboles) ; plusieurs runes = un accord. |
| **Échoïde** | Créature née d'une structure runique instable, mémoire de son créateur. |
| **AMRU** | Autorités Magiques du Royaume-Uni, autorité centrale. |
| **Ascendance** | Groupe déclaré extrémiste dangereux ; a tenté un coup d'État en 2026 ; rejette l'isolement du monde magique. |
| **Cercle de/du Frêne** | Organisation secrète opposée à l'Ascendance (Glenwood y aurait appartenu). |
| **Grand Confinement** | 1944-1945, décrets d'isolation du monde magique (Cassiopée Valemont), renforcés en 2026. |
| **Secret magique** | Le fait de ne pas exposer la magie aux Sans-Flux ; défendu strictement par Alistair Valemont. |
| **Razeball / le Raze** | Sport international sorcier (ex-Razorball). |
| **Cœur** | Le but du Razeball. |
| **Couronnes** | La monnaie (règlement : arnaque max 2500 Couronnes). |
| **Briseflux / Brise-Flux** | Centre pénitentiaire, prison (zone RPK). |
| **Flamme Ouverte** | Festival de 1463 ouvert à toutes les entités magiques (Hearthbane). |
| **Tunnel du Faux Pas** | Dispositif inspiré du réseau runique détourné en 1666. |
| **Chaudronnerie** | Domaine dissimulé des Belladorn. |
| **Méthode Ravenscroft** | Neutraliser un système runique instable section par section. |
